# 🧩 Slitherlink - Application Shiny en R

## 📌 Description

Ce projet consiste en la création d’une application interactive du jeu **Slitherlink** 
à l’aide du package **Shiny** en R.

Slitherlink est un puzzle logique dans lequel le joueur doit tracer une **boucle fermée unique** 
sur une grille en respectant des contraintes numériques.

Chaque nombre indique combien de segments doivent entourer la case.

---

## 🚀 Fonctionnalités

- 🎮 Génération automatique de grilles
- 📏 Choix de la taille de la grille
- ⚙️ Trois niveaux de difficulté :
  - Facile
  - Moyen
  - Difficile
- 🖱️ Interaction par clic pour tracer les segments
- 🔍 Vérification automatique de la solution :
  - respect des contraintes
-  Réinitialisation de la partie

---

## 🧠 Règles du jeu

- Tracer une **seule boucle fermée**
- La boucle ne doit **ni se croiser ni se ramifier**
- Chaque case numérotée indique le nombre de segments autour de celle-ci

---

## 🛠️ Technologies utilisées

- **R**
- **Shiny**
- **bslib** (pour le design de l’interface)
